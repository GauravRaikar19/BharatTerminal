# BharatTerminal

High-performance real-time Indian Stock Market terminal engine (NSE & BSE) built with Vanilla JavaScript, HTML5, and Node.js.

## Features
- **Real-Time Market Tracking**: Live quotes for NIFTY 50, SENSEX, BANK NIFTY, and leading Indian equities via Yahoo Finance (.NS tickers).
- **Interactive Portfolio**: Track invested capital, current market value, real-time P&L, and returns with auto-fill CMP helpers and price verification safeguards.
- **Advanced Technical Indicators**: Real-time RSI, MACD, Bollinger Bands, and AI-driven quantitative trend signals.
- **Backtesting Engine**: 2-year backtest model factoring in market regime filters, volume surges, and profit-lock exits.
- **Market News & Sentiment**: Real-time market headlines, sentiment categorization, and Fear & Greed index.

## Getting Started
1. Run the terminal backend server:
   ```bash
   node server.js
   ```
2. Or use the quick-start batch script on Windows:
   ```cmd
   start.bat
   ```
3. Open `http://localhost:3000` in your web browser.
